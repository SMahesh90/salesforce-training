# Day 3: Data Management

## 1. What is Data Management?
Data management is how a company collects, keeps, and uses its information safely and correctly. It is like organizing a huge digital filing cabinet so that anyone can find what they need quickly and trust that the information is right.

## 2. What is Data Loader?
Data Loader is a tool used to move large amounts of data. You use it when you need to add, change, or delete thousands of records (up to 5 million) at one time. It is a separate app that you download to your computer.

## 3. Difference Between Import Wizard and Data Loader

| Feature | Import Wizard | Data Loader |
| :--- | :--- | :--- |
| **Where is it?** | Inside the web browser. | An app on your computer. |
| **How much data?** | Up to 50,000 records. | Up to 5,000,000 records. |
| **Ease of use** | Very easy for beginners. | A bit harder; for experts. |
| **Can it delete?** | No. | Yes. |

## 4. Data Migration Challenges (Problems when moving data)
Moving data from one system to another is hard because:
*   **Wrong Format:** Dates or phone numbers might look different in the old and new systems.
*   **Too Much Data:** Moving millions of rows can take a long time and might crash.
*   **Mapping Errors:** Putting the "Name" into the "Address" box by mistake.
*   **Missing Info:** Some old records might be empty or incomplete.

## 5. Data Quality Problems
Data is "bad" when it has these problems:
*   **Duplicates:** The same person is listed three times.
*   **Old Data:** Using an address or phone number from 10 years ago.
*   **Spelling Mistakes:** Writing "Johnn" instead of "John."
*   **Empty Boxes:** Missing important info like an email address.

## 6. Reflection: Why is clean data important for decision making?
Clean data is very important because if the data is wrong, the decision will be wrong. 

*   **Trust:** If the data is clean, managers can trust their reports.
*   **Saving Money:** If you have clean addresses, you don't waste money sending mail to the wrong house.
*   **Better Service:** If you know exactly what a student needs, you can help them better.
*   **Correct Choices:** It is like using a map. If the map (the data) is wrong, you will get lost. If the map is clean and clear, you will arrive at the right place.
